The runtime PNG is an unchanged copy. Tara and the signature treatment come directly from this approved image. No replacement image generation, stock imagery, third-party font, or additional dog photo is required. The ten earlier reference photos are not included because they are not runtime dependencies.

The inline SVG views in index.html and assets/artwork-map.json select the original hero, goal cards, Restructure, and discovery cards. Local SVG clipping follows the irregular goal silhouettes. A narrow text-free left-edge region supplies ambient colour. The mobile Restructure view reuses the original landscape with live labels and a local line icon.

Branded lettering and illustrated card labels are baked into the approved image. Accessible labels exist in the DOM; Larger text exposes live text captions. This is intentionally an artwork-preserving implementation, not a fabricated set of original layered exports.
