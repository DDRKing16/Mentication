# MentiCation Visual Assets

This library contains the current intervention design boards, MentiCation-branded production concepts, and standalone screen images.

## Shared brand treatment

- Contemporary humanist sans-serif UI typography, aligned to the app's Hanken Grotesk direction.
- The fluid handwritten MentiCation wordmark is used sparingly as the product signature.
- Each intervention retains its own cinematic environment, colours, objects, animation language, sound direction, and therapeutic metaphor.
- Earlier visual iterations are retained separately and are not the preferred implementation references.

## Folder structure

- `00 Brand Reference`: source brand marks and style reference.
- `Ignition Point`: boards, the branded six-screen concept, individual screens, and earlier visual explorations.
- `Box Breathing`: boards, the branded single-square breathing sequence, individual screens, and earlier visual exploration.
- `5-4-3-2-1 Grounding`: board, branded sensory visual system, and standalone core screen.
- `Thought or Fact`: complete boards, branded Mind Court engine concept, and five standalone screens.
- `Urge Surfing`: complete board, branded Choice Window concept, and five standalone screens.
- `Progressive Muscle Relaxation`: branded six-screen concept and six standalone screens.

## Preferred files

Use files under `Screen Concepts` and `Individual Screens` for implementation or presentation. Use `Boards` for product specification. Files under `Earlier Iterations` are included for design history only.
