A meaningful event is a confirmed answer, an explicit attempt report, or a fully elapsed guidance unit. Choosing a proposed action is labelled as a choice, never doing it. Each pair reveals its actual evidence or a useful next instruction. Navigation, settings, typing drafts, skipped practice, replays of history and repeated confirmations add no events. Baseline entry/navigation supplied by the route harness is not claimed as a performed exercise. Timed guidance indicates elapsed guidance, not verified physical participation or relief.

## Evidence boundaries

The linked traces distinguish full walkthroughs from focused checks. This is coverage of all 20 reachable interventions, not a claim that every possible combination of optional answers was replayed in a browser. Existing unit suites cover branch/reducer semantics beyond these recordings. Vector Shift evidence uses the accessible route; alternative visual-task variants are not all replayed here. Tapping evidence exercises a real partial interval and interruption, with full round/point accounting covered by automated protocol tests. PMR evidence exercises skip/stop/resume rather than waiting through every full-length region. No physical tapping, breath quality, clinical benefit, native audio/haptics, VoiceOver/TalkBack audition, device suspension or closed-phone delivery is certified by muted Chromium. Separate physical-device review remains appropriate before deployment.

The dense all-equal-importance Good Map fixture has overlapping map-marker hit targets. Its optional context was opened with native keyboard activation; the existing List view is the alternative navigation surface. Map geometry was not redesigned in this checkpoint change.
