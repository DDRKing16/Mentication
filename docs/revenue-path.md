# Revenue path

V1 stays a complete free app. All 25 interventions remain available without an account.

## Why free first

The category is crowded with subscriptions people ignore. Mentication wins if the first reset actually changes state. Trust is the distribution system.

## Path to millions

1. **Free App Store V1** — acquisition and proof. North-star metric is first-week completed resets, not downloads.
2. **Apple IAP programs** — depth around the same 25 mechanisms. Examples — 14-day rumination nights, cannot-start-work mornings, sleep-struggle week. Annual price in the premium wellness band. Restore purchases required.
3. **Workplace and university licenses** — same player, private by default, optional aggregated completion stats only if privacy contract is rewritten.
4. **Clinician companion** — assign a short protocol; the patient app stays local-first.
5. **Adjacent toolkit** — facilitation scripts and program design sold as a high-ticket digital product beside the app.

## Hard boundary

If a digital feature is gated in iOS, use Apple In-App Purchase. Do not restore a web checkout inside the native application.
