are background artwork for Opening Pull, Trajectory Choice, Committed Move and

code rather than baked into these images.

OPEN CHANNEL, THEN WHAT? AND NIGHT CHANNEL

These folders currently contain optional early hero concepts only. They are not
complete intervention boards and should not be treated as final UI direction.

BUILD RULES

- Use each Design_Board.png as the primary specification.
- Preserve the therapeutic sequence, branching, safety checks and return states.
- Build text, controls, timers, motion and responsive behaviour natively in code.
- Use image assets as supporting visual layers only.
- Maintain an elite contemporary technology aesthetic: restrained, premium,
  minimalist and highly legible rather than futuristic or visually overloaded.
- Do not add points, streaks, confetti, badges or generic encouragement.
- Offline-action interventions must allow the user to leave the app and return;
  the app should not require remaining open unless the design board specifies it.

The Template folder contains the reusable blank Intervention Design Board.
Superseded boards, failed generations and incorrect text versions are excluded.
